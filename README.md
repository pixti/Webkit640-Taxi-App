### **[Taxi.App]**

## 🚕 React Native 와 Node.js를 활용한 택시 호출 앱 서비스

이 Taxi.App Project는 
Webkit640 7기 (2025년 대학·기업 협력형 SW아카데미 사업 풀스택 개발자 양성과정 7기)에 공통 과제로 제출한

React Native와 Node.js를 활용한 택시 호출 앱 서비스 입니다. 

기본적인 프론트엔드, 백엔드, 서버를 TypeScript로 구현하고, 구글 맵 API(Google Maps Platform) 를 활용해 실제로 어느정도 동작하는 수준까지 구현하여 제출했습니다.
Api 특성상 국내 지역은 지역 탐색이 어렵고 미국 지역으로 테스트를 해야했습니다.
